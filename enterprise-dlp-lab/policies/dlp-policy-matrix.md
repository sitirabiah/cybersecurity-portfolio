## DLP Policy Matrix

| Policy name | Detection condition | Enforcement |
|---|---|---|
| DLP-001-Restricted-Email-External | Restricted data sent externally | Block |
| DLP-002-Confidential-USB-Transfer | Confidential data copied to USB | Block with controlled exception |
| DLP-003-Restricted-Cloud-Upload | Restricted file uploaded to prohibited cloud domain | Block |
| DLP-004-Confidential-External-Sharing | Confidential document shared externally | Restrict / warn |
| DLP-005-Restricted-Endpoint-Activities | Restricted data printed or copied | Block |
| DLP-006-Sensitive-Data-Discovery | Sensitive information in legacy repositories | Audit and investigate |
