## SC-007: On-premises data discovery

**Risk:** Preventive foundation

**Situation:** GML discovers that legacy file servers contain unclassified customer records and financial information.

| Element | Design |
|---|---|
| Channel | On-premises file shares |
| Detection | Sensitive Information Types |
| Action | Discover, classify and prioritise remediation |
| Override | Controlled repository access exceptions |
| Investigation | Identify owners, permissions and sensitive data locations |

**Suggested:** We cannot design effective protection without understanding where sensitive information resides, who can access it and whether the permissions are appropriate.
